# Sitio Web Personal & Portafolio - Juan Esteban Vallejo

Este repositorio contiene el proyecto desarrollado para **El Reto: Proyecto Sitio Web Personal**.

---

## 📋 Requisitos del Reto y Cumplimiento

| Requisito | Estado | Descripción |
| :--- | :---: | :--- |
| **Tema Personal** | ✅ | Portafolio profesional, perfil, hobbies/intereses y trayectoria de Juan Esteban Vallejo. |
| **Estructura** | ✅ | Incluye las secciones solicitadas: **Inicio**, **Acerca de**, **Pasiones & Hobbies**, **Portafolio (Proyectos)** y **Contacto**. |
| **HTML Semántico** | ✅ | Implementación estricta de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<aside>`, `<form>` y `<footer>`. |
| **CSS Externo** | ✅ | Archivo modular `styles.css` con variables CSS, Grid, Flexbox y navegación fluida. |
| **Sin Frameworks** | ✅ | Desarrollado con 0% dependencias externas, sin Bootstrap, Tailwind ni plantillas de terceros. |
| **Calidad de Código** | ✅ | Indentación limpia, estructura ordenada, accesible y diseño adaptativo (*responsive design*). |

---

## 🚀 Estructura del Proyecto

```text
cvv/
├── index.html       # Estructura semántica del sitio web personal
├── styles.css       # Estilos personalizados (CSS3 puro)
├── perfil.png       # Fotografía de perfil del autor
└── README.md        # Documentación del proyecto
```

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico**: Estructura accesible y jerarquía clara de contenidos.
- **CSS3 Puro**:
  - Variables CSS (`:root`) para temas y diseño consistente.
  - Maquetación con **CSS Grid** y **CSS Flexbox**.
  - Efectos visuales modernos (*Glassmorphism*, transiciones suaves y estados *hover*).
  - Media Queries para diseño responsivo en móviles, tablets y computadoras.
